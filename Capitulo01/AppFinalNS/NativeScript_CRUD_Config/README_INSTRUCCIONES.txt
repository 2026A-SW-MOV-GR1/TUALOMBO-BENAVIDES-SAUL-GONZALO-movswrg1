INSTRUCCIONES PARA USAR ESTOS ARCHIVOS

1. Descomprime este ZIP.
2. Copia la carpeta "src" dentro de la raíz de tu proyecto NativeScript:
   D:\RepositorioAPPMoviles\TUALOMBO-BENAVIDES-SAUL-GONZALO-movswrg1\Capitulo01\MiAppVisual\MiAppNativaNuevo
3. Acepta reemplazar los archivos existentes.
4. Si creaste antes src/app/app.module.ts, bórralo o déjalo sin usar. Este proyecto usa componentes standalone.
5. Verifica que NO exista texto "Hola mundo" en src/app/app.component.html.
6. Desde la raíz del proyecto ejecuta:
   ns clean
   ns run android
