PROYECTO NATIVESCRIPT ANGULAR - CRUD DE ITEMS

IMPORTANTE:
Este proyecto NO se ejecuta desde la carpeta Capitulo01 principal de Android Studio.
La carpeta Capitulo01 principal contiene otra app Android nativa en Kotlin que muestra "Hola Mundo".

Para ejecutar este CRUD, abre PowerShell exactamente dentro de esta carpeta:
MiAppNativaNuevo_CORREGIDO

Debes ver estos archivos en la carpeta:
- package.json
- nativescript.config.ts
- src
- App_Resources

COMANDOS DESDE CERO:
1) Instalar NativeScript CLI si no lo tienes:
   npm install -g nativescript

2) Instalar dependencias del proyecto:
   npm install

3) Verificar Android:
   ns doctor android

4) Limpiar compilaciones antiguas:
   ns clean

5) Ejecutar en Android:
   ns run android

Si te sigue saliendo "Hola Mundo", estás ejecutando la app Android nativa equivocada.
El archivo que contiene "Hola Mundo" en tu ZIP original era:
Capitulo01/app/src/main/res/values/textos.xml
Ese archivo NO pertenece a este proyecto NativeScript corregido.
